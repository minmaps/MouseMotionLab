# MouseMotionLab ML

Le package `mousemotion` prépare les captures SQLite, entraîne le modèle de durée et la
diffusion 1D, évalue les trajectoires et expose le générateur JSON utilisé par l’application WPF.

Le [guide d’intégration du modèle](../docs/integration-modele.md) explique comment appeler
le générateur depuis Python ou C# et rejouer ses deltas dans un logiciel de mouvements de souris.
